## 安卓 APK

每次推送到 `main`，GitHub Actions 会自动构建已签名的 APK，并发布到 Releases：

- 下载地址（固定）：`https://github.com/suofengying981-lang/card_game/releases/download/apk-latest/qipai.apk`
- 手机上下载后允许「安装未知应用」即可安装；之后的新版本直接覆盖安装，游戏进度保留（所有版本使用同一把签名）。
- 安卓 app 用 Capacitor 把网页打包进 APK，离线可玩。构建配置见 `.github/workflows/android.yml`，安卓工程在 `android/`。
- 签名密钥 `android/app/qipai.keystore` 为个人自用，随仓库公开；不要用它发布到应用商店。

## 斗地主玩法

- 三人对战，一个地主对两个农民；地主多拿 3 张底牌并先出。
- 叫分最高者当地主，叫 3 分直接成为地主；无人叫分则重新发牌。
- 牌型：单张、对子、三张、三带一/二、顺子（5 张起）、连对（3 对起）、飞机（带单/带对）、四带二、炸弹、火箭。
- 每出一个炸弹倍数翻倍，春天 / 反春天再翻倍。地主赢得 2×（底分×倍数），农民各得 1×。
- 操作：点牌，或在手牌上滑动来选牌，再点「出牌」；「提示」可连续点击切换方案。积分保存在本机浏览器中。

## 斗地主电脑水平

菜单里可选三档（默认「困难」），设置保存在本机：

| 档位 | 做了什么 |
| --- | --- |
| 简单 | 基础启发式：手牌拆分估算 + 出小牌/压牌评分 |
| 普通 | 加上记牌（统计场上未出现的牌，判断哪手牌没人压得过）和农民配合（不压队友、给快走完的队友送牌） |
| 困难 | 再加蒙特卡洛推演：随机补全对手手牌（地主底牌已知），对每个候选出法用快速策略打完整局统计胜率；叫牌也用模拟胜率决定。每步最多约 0.5 秒，分片计算不卡界面 |
| 神经网络 | 自对弈强化学习训练的网络（`rl/`，权重 `ddz_nn.bin` 约 4.4 MB，选到该档才下载）。只负责出牌，叫牌沿用困难档的模拟。当前权重训练了 40.8 万步、约 2.3 亿局自对弈：当农民时明显强于「普通」，当地主时与「普通」接近，仍不及「困难」；与 5.7 万步的旧权重直接对打胜率约 52%，提升有限（自对弈训练后期进步很慢） |

对战验证（同牌换位、各千余局）：困难对普通约 74% 胜率，叫牌模拟比旧的手牌强度叫牌平均每局多赢约 0.5 分。

## 德州扑克

- 无限注现金桌：你 + 4 个电脑对手（老王稳健、小李激进、阿杰爱诈唬、陈姐均衡），初始筹码 2000，盲注可选 10/20、25/50、50/100。
- 完整规则：盲注轮转、最小加注、全下不足额加注不重开、多边池、平分底池、单挑位置规则。
- 加注用滑条 + 最小/½池/¾池/满池/全下 预设；可开关「胜率提示」（蒙特卡洛估算）。
- **智能提示**（菜单里可开关）：轮到你时给出「弃牌 / 过牌 / 跟注 / 加注」建议，并说明理由——对比你的有效胜率和底池赔率所需胜率；翻牌前给起手牌评级；翻牌/转牌给出补牌张数和成牌概率（如同花听牌 9 张）。仅供参考，电脑可能诈唬。
- **声音**：发牌、翻牌、过牌、跟注、加注、全下、弃牌、轮到你、赢/输都有音效；另有可选的轻柔背景音乐（默认关）。全部由浏览器现场合成，无需下载音频，离线可用。菜单里可单独开关「音效」「音乐」，顶栏的喇叭按钮一键全关/恢复。
- 筹码输光可重新买入；电脑筹码过少自动补充；战绩与筹码保存在本机浏览器。

## 桥牌

- 合约桥牌：你坐南家，北家电脑是搭档，东西家是电脑对手。叫牌 → 定约 → 打牌（庄家代打明手）→ 复式计分；庄家与身价按 16 副一轮轮转，累计得分保存在本机。
- 叫牌盒支持过牌 / 加倍 / 再加倍；「提示」给出叫牌或出牌建议（叫牌会说明你的点力和牌型）。
- **电脑叫牌（自然体系）**：12+ 点开叫、5 张高花；1NT=15–17 平均牌型，2NT=20–21，2♣=强牌 22+（逼叫到局）；2♦/♥/♠ 弱二，3 阶以上阻击；1 阶 8+ 点、2 阶 11+ 点争叫；技术性加倍及应叫；4NT 黑木问 A。无斯台曼、转移等约定叫。核心做法：把每一轮叫品解释成点力区间 + 花色长度，再用「我的点力 + 搭档点力估计」决定目标定约。
- **电脑打牌**：开叫引牌按经验规则（连牌顶张、第四大、搭档叫过的花色）；之后用确定化蒙特卡洛：补全看不见的两家手牌（遵守「缺门」和叫牌推断的点力/长度约束），用启发式打完整副牌，选使本方平均赢墩最多的牌。不读取任何看不见的手牌。三档水平控制推演时间（简单 / 标准 ≈0.3 秒 / 强 ≈0.9 秒）。
- 对战验证（同牌同叫牌，120 副）：推演庄家比纯启发式庄家平均多赢约 0.36 墩，推演防守让庄家少赢约 0.64 墩。

## 掼蛋

- 4 人 2 副牌，你（南）和对家（北）一伙；本局「打几」的级牌仅次于大小王，**红桃级牌是百搭**。
- 牌型：单张、对子、三张、三带二、顺子（A 可作 1 或 14）、木板（3 连对）、钢板（2 连三）；炸弹：4～8 张同点、同花顺、天王炸（4 张王），大小顺序：天王炸＞8＞7＞6＞同花顺＞5＞4。
- 升级：双上升 3 级、头游+三游升 2 级、头游+末游升 1 级；2 打到 A，A 级需要双上或头游+三游才算通关。下一局自动进贡 / 还贡（抗贡：进贡方握两张大王）。
- 电脑：枚举全部合法出法（含百搭补位），先手出小而长的牌型、不轻易拆炸弹，跟牌出最小压牌，队友领先不压，对手快走完才用炸弹。两档水平。

## 跳棋

- 121 孔六角星棋盘，每人 10 子，2 人（上下对角）或 3 人（三角）。走一格，或隔一子（任何一方）跳到对面空位，可连跳；先把 10 子全走进对面三角者胜。
- 电脑：以「到目标角的距离总和」为评估，困难档在 2 人局会预判你的最佳回应。支持悔棋。

## 军旗

- 每方 25 子（司令～工兵、炸弹 2、地雷 3、军旗 1），对方子面朝下。开局可随机布阵、点两子互换（军旗只能在大本营、地雷放后两排、炸弹不放第一排）。
- 走法：每步一格（行营内可斜走）；铁路上可直线走任意格，工兵可在铁路上拐弯；中间前线只有 3 座桥。行营里的子不可被吃。大吃小、同级同归于尽，炸弹碰谁都同归于尽，地雷只有工兵能排，扛掉军旗或让对方无子可动即胜。
- 电脑：只使用公开信息（已阵亡的子、哪些子动过、赢过 / 输过谁）推断你的子，对每步估算期望得失并考虑被反吃的风险。三档水平。

## 在手机上使用

部署到 GitHub Pages 后，用手机浏览器打开链接即可。

- iPhone：Safari → 分享 → 添加到主屏幕。
- Android：Chrome → 菜单 → 安装应用 / 添加到主屏幕。

首次打开后会缓存到本机，之后无网络也能玩；更新会在下次打开时自动生效。

## 本地运行

```bash
python3 -m http.server 8000   # 然后访问 http://localhost:8000
```
